## 这是什么？
一款以公寓邻里为主题的浏览器塔防小游戏，由余家欣（夹心）策划，使用 AI 辅助设计与开发。HTML、CSS 与原生 JavaScript 实现，无需账号。

- 七夜关卡：从基础布阵到跨层路线与巨怪挑战。
- 六种住户：发电仓鼠、拖鞋阿姨、沙发路障、冰箱男、暴躁奶奶、梦游维修工。
- 电梯调兵：把住户送到另一层同列空位，应对不同楼层的压力。
- 动态公寓首页、四种彩蛋、住户图鉴、邻居来信与 21 枚挑战贴纸。
- 第四夜起使用左侧住户栏；首领弱点阶段持续推进，保留攻击预警。

## 怎么玩
1. 收集电量，选择住户，再点击空格部署。
2. 仓鼠产电；沙发放前排；输出住户在后排。
3. 电梯：点击支援 → 选择住户 → 点击另一层同列空位。沙发不能运输。
4. 留意首领蓄力和弱点提示，必要时撤回或调兵。

快捷键：`1–6` 选住户，`空格` 暂停，`Esc` 取消。小屏幕建议横屏。

## 下载与本地运行
在 Releases 下载 `Sleepy-Apartment-v0.24.1-web.zip`，先完整解压，再打开 `index.html`。如浏览器限制本地媒体，请安装 Python 3，在解压目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

随后打开 `http://127.0.0.1:8000`。这是浏览器版，不是 Windows 安装程序。首次运行请验证声音与视频可播放；已完成自动逻辑测试，真机兼容性仍需持续反馈。
